# Проект "AskPupkin" — Сервис вопросов и ответов

Учебный проект в рамках курса VK Education "Web-технологии". Сервис позволяет пользователям задавать вопросы, отвечать на них, голосовать за лучшие решения и формировать сообщество.

## Технологии на данном этапе:
*   **Верстка:** HTML5, CSS3.
*   **Фреймворк:** Bootstrap 5.3, подключенный локально.
*   **Адаптивность:** Реализована сетка для десктопов (>=1200px), планшетов (768px) и мобильных устройств (375px).

## Как запустить верстку:
На текущем этапе  проект представляет собой статические HTML-страницы. Для просмотра:
1. Клонируйте репозиторий: `git clone <ссылка_на_ваш_репозиторий>`
2. Перейдите в папку `public/`.
3. Откройте файл `index.html` в любом браузере.

## Список страниц и роутов
Все макеты страниц находятся в папке `public/`:

*   **Главная страница** (`index.html`) — Листинг новых вопросов с пагинацией и сайдбаром.
*   **Страница вопроса** (`question.html`) — Полный текст вопроса, список ответов и форма добавления нового ответа.
*   **Добавление вопроса** (`ask.html`) — Форма создания нового вопроса с полями для заголовка, текста и тегов.
*   **Авторизация** (`login.html`) — Форма входа в систему с примерами отображения ошибок.
*   **Регистрация** (`signup.html`) — Форма создания аккаунта с возможностью загрузки аватара.
*   **Настройки профиля** (`profile.html`) — Страница изменения данных пользователя и его аватара.

## Структура проекта
*   `public/` — HTML-файлы страниц.
*   `public/static/css/` — Стили Bootstrap.
*   `public/static/js/` — Скрипты Bootstrap.
*   `public/static/img/` — Изображения, иконки и аватарки пользователей.
*   `.gitignore` — Игнорирование служебных файлов IDE, кэша Python и системного мусора.
